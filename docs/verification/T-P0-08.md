## BLOCCO — input richiesti dal contratto approvato

**Descrizione:** mancano valori che il formato 1 richiede esplicitamente,
non sostituibili con default o segnaposto operativi.

**Evidenze:**

1. Il flow e manifest SIOC ricevuti elencano dodici dataset required=true,
   tutti PENDING_DATASET. Nessuno dei file ufficiali/relative versioni è
   presente nel repository; le [schede](../normative/reference-datasets.md)
   ne riportano le lacune. Il nuovo binding richiede versione/path/SHA-256;
   nessun hash o release viene inventato. I dataset sintetici dimostrativi
   dell’authoring non sono fonti normative SIOC.
2. La fonte dichiara encoding runtime_required senza code page. Il controllo
   no_lowercase_if_present su 1.7 e 1.8 richiede un profilo lessicale di
   minuscole esplicito; AN non implica automaticamente ASCII-only.
3. Il derivato SIOC age_at_admission_years richiede la convenzione di
   compleanno 29 febbraio negli anni non bisestili. Il formato approvato
   ammette feb28/mar01 senza default; mar01 dell’esempio è soltanto sintetico.
4. La reference spec SIOC richiede compatibilità ICD9 sex/min_age/max_age;
   mancano dati/versioni e dettagli reali necessari a verificare binding e
   valori nulli/non vincolati. Non si tolgono questi controlli per compilare.

**Impatto:** non si producono canonical flow/trace con binding fittizi,
policy normative dedotte o regole obbligatorie disabilitate. Lint manuale
sul profilo completo e testimoni normativi lookup/età restano da eseguire.
Nessun file di schema sorgente FROZEN è modificato, nessuno schema incompleto
è pubblicato come eseguibile. T-P0-09 non inizia con prerequisito mancante.

**Attività indipendente svolta:** piano e catalogo fixture, tracciabilità e
contratto di output, preservando tutti i riferimenti ai vincoli ricevuti.
Non implementati validatori, compiler, storage o UI.

**Decisioni/input richiesti all’autore:** posizione/fonti dei dataset ufficiali,
profilo encoding/caratteri e convenzione feb28/mar01. Le domande sono state
presentate; nessuna risposta è inferita dall’assenza di un messaggio.
Il preflight non prova che i file non esistano fuori dal workspace accessibile.
