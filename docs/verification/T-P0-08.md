## Ispezione aggregata degli export autorizzati

Solo lettura in memoria per statistiche tecniche, nessuna riga o valore
paziente stampato, copiato, versionato o usato come fixture.
Sette file esaminati nella directory indicata dall’autore, identificati qui
solo per ordine lessicografico: non sono una fonte di nuove regole normative.

| Ordinale | Righe | Lunghezze byte senza terminatore | Osservazione tecnica |

| 1 | 219 | 418 | ASCII, CRLF |
| 2 | 219 | 483 | ASCII, CRLF |

| 4 | 392 | 347 | ASCII, CRLF |
| 5 | 2 | 606 | ASCII, CRLF |
| 6 | 2 | 101 | ASCII, CRLF |
| 7 | 0 | — | Vuoto |

Nessun BOM UTF-8; tutti decodificabili UTF-8, dato insufficiente per scegliere
una codifica univoca. Cinque file uniformi non contengono minuscole ASCII;
uno eterogeneo sì, senza dedurne modifiche del repertorio normativo.
Le larghezze uniformi differiscono dalle fonti di 212 byte per i primi
quattro layout e 34 per l’ultimo: **non prova un prefisso da rimuovere**.
Nessuna rimozione, padding o spostamento posizioni viene introdotto.
Prima di usare questi export come input del futuro validatore, occorre
chiarire il loro formato di esportazione. Ciò non impedisce la bozza basata
sui layout normativi e sui dati esclusivamente sintetici previsti dalle task.
