## Limiti e handoff

Come approvato, l’audit non rileva modifiche concorrenti che mantengono
la dimensione; niente locking o snapshot dei file. Il mutex è dello stato
in memoria, non della sorgente. File regolari tramite open; Read generico
tramite wrap con metadati espliciti e controllati.

InputError/ReportError: non è implementato o simulato come runtime completo.
