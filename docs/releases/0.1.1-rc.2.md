# Lintra 0.1.1-rc.2 — prova privata T-P18-03

Nuova prerelease per collaudare il runbook con il codice successivo a rc.1.
Non sostituisce né modifica la release privata immutabile 0.1.1-rc.1.

Include il core storico SQLite qualificato, provider di chiave esterna, API/CLI
per preview e revisione, UI Slint e limite max_errors dell’API ratificato DEC-16 A.
La pubblicazione release.yml distribuisce soltanto CLI Linux GNU e Windows MSVC;
non distribuisce la UI, un installer, un archivio storico o chiavi operative.
Il bundle incorporato resta la dimostrazione SYNTHETIC, non un profilo normativo
CAD né la certificazione di eseguibilità del profilo SIOC completo.

I tre golden summary SIOC cambiano soltanto validator_version. Regole,
conteggi, byte JSONL e baseline normative sono invariati. La UI segue la stessa
versione di workspace, ma richiede packaging separato già qualificato dal proprio
gate: non presumere un asset UI in questa release.

Uso interno/personale secondo DEC-RELEASE-SETUP-01 A. Nessuna firma Authenticode;
GNU vincolato alla glibc effettivamente registrata in BUILD.json. Policy per dati
reali, cifratura, retention e backup completo ancora aperte. Una nuova versione
non approva queste decisioni e non autorizza la migrazione dello storico.

Stato di pubblicazione e verifiche: docs/verification/T-P18-03-release-runbook.md.
