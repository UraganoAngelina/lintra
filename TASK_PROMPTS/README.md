# Prompt operativi correnti

Questi51 prompt sono copie versionate delle task non DONE alla migrazione
GOV-2026-10-26-01. Le sole modifiche rispetto al kit sorgente sono clausole di
avanzamento/handoff, registrate in docs/governance/migration-manifest.json.
Obiettivi, prerequisiti, contratti, test, accettazione ed esclusioni sono invariati.

Prima di ogni task leggere AGENTS.md GLOBAL AGENT EXECUTION POLICY e il master
prompt della root. Eseguire soltanto lo scope della task corrente, poi avanzare
alla prossima READY senza delega o conferme ordinarie. I gate umani reali restano.
I riferimenti legacy SOURCE_DOCUMENTS/<file> si risolvono in docs/<file>; le fonti
normative del kit non presenti nel repo restano input esterni, mai dati inventati.
Non ricopiare contenuti paziente. Non applicare lo stato iniziale del kit al repo.
