Development/demo content only, not a regional normative profile or official
reference dataset. SYNTHETIC/v1 is copied byte-for-byte from the existing
application test fixture. SYNTHETIC_CODES/v1 contains the exact byte keys 001
and 002 for provider qualification; the demonstration schema has no reference
dependency and does not claim to execute those lookups.

README or the manifest itself. No real patient data, normative schema or official
reference table is invented. Selecting a missing flow/version remains an error.
